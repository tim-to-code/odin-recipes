# Odin recipes

Un site de recettes statique, construit dans le cadre du curriculum
The Odin Project (Foundations).

## Objectif

Premier projet HTML du parcours. Il s'agit d'une page d'accueil
qui liste des recettes, chacune renvoyant vers sa propre page.

## Competences demontrees

- Structure d'un document HTML
- Titres, paragraphes, listes ordonnees et non ordonnees
- Liens entre pages du meme projet
- Organisation des fichiers et dossiers d'un projet web
- Workflow Git : add, commit, push
